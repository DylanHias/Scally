CHANGES MADE BY SCALLY
The published PyTorch weights were converted to a Core ML package for
on-device inference on Apple silicon. The conversion casts the weights to
float16 and traces the network at a fixed 256x256 tile size. The network's
arithmetic is otherwise unaltered: the converted model matches the author's
own ONNX export to 6.3e-6 in the worst pixel, and the float16 Core ML package
matches the float32 PyTorch reference to roughly 1% of output range on
photographic input.

ARCHITECTURE
RealPLKSR, from "Partial Large Kernel CNNs for Efficient Super-Resolution"
(arXiv:2404.11848), as implemented by the neosr project
(https://github.com/neosr-project/neosr).
